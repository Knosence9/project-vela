* ADR-0044: Read-only exact finite recurrence occurrence CLI paging
:PROPERTIES:
:CUSTOM_ID: adr-0044-read-only-exact-finite-recurrence-occurrence-cli-paging
:END:
- *Status:* accepted
- *Date:* 2026-08-02
- *Decision and execution issue:* [[https://github.com/Knosence9/project-vela/issues/873][#873]]
- *Related:* ADR-0039, ADR-0043

** Context
:PROPERTIES:
:CUSTOM_ID: context
:END:
ADR-0039 defines allocation-bounded deterministic occurrence paging over one immutable finite recurrence. ADR-0043 exposes exact durable recurrence lookup without scanning unrelated streams. Operators still cannot compose those boundaries through the developer CLI without writing a custom adapter.

The smallest responsible slice is an exact read-only command that validates caller-owned coordinates, loads one selected definition, and delegates arithmetic to the existing kernel projection.

** Decision
:PROPERTIES:
:CUSTOM_ID: decision
:END:
=vela-dev recurrence occurrences DATABASE RECURRENCE_ID START_OFFSET PAGE_SIZE= validates =RECURRENCE_ID= through =RecurrenceId= and =PAGE_SIZE= through =OccurrencePageSize= before storage access. It then opens only the selected existing database through =RecurrenceStore::open_read_only=, loads only the selected stream through =RecurrenceStore::load=, and delegates projection to =FixedIntervalRecurrence::occurrences_page=.

Success emits one compact JSON object. Its =occurrences= array is ordered by ascending offset; every element preserves exact =recurrence_id=, =goal=, =offset=, =unix_millis=, and =definition_revision=. =next_offset= is the first unreturned authored offset, or =null= on the final truncated page.

Invalid IDs emit =invalid_recurrence_id=, and zero or oversized page sizes emit =invalid_occurrence_page_size=, all before storage access. An absent definition emits =recurrence_not_found=; an invalid start emits =recurrence_occurrence_out_of_range=. Storage open, exact replay, projection infrastructure, and serialization failures emit =recurrence_occurrence_lookup_failed=. Every failure returns non-zero, emits one escaped diagnostic, and emits no stdout. A missing database remains missing, and unrelated stream corruption cannot block exact paging.

The command is read-only and inert. The returned offset is a projection coordinate, not persisted cursor, identity, lifecycle revision, due or catch-up decision, claim, permission, or execution evidence. The command reads no ambient time and cannot mutate definitions, persist occurrences, materialize tasks, claim, cancel, dispatch, retry, or execute work.

** Alternatives considered
:PROPERTIES:
:CUSTOM_ID: alternatives-considered
:END:
*** Page the recurrence inventory and filter it
:PROPERTIES:
:CUSTOM_ID: page-the-recurrence-inventory-and-filter-it
:END:
Rejected because exact durable lookup already exists. Inventory scanning adds unrelated work and lets unrelated corruption block a caller-selected projection.

*** Reimplement interval arithmetic in the CLI
:PROPERTIES:
:CUSTOM_ID: reimplement-interval-arithmetic-in-the-cli
:END:
Rejected because =FixedIntervalRecurrence::occurrences_page= is authoritative for bounds, ordering, provenance, overflow safety, and cursor semantics.

*** Return an empty page for an invalid start
:PROPERTIES:
:CUSTOM_ID: return-an-empty-page-for-an-invalid-start
:END:
Rejected because ADR-0039 distinguishes invalid projection coordinates from valid final pages.

** Consequences
:PROPERTIES:
:CUSTOM_ID: consequences
:END:
- Operators can page exact durable recurrence projections through deterministic machine-readable output.
- Input validation and bounded allocation remain owned by kernel value types.
- Exact-stream replay preserves the narrowest storage authority and corruption boundary.
- No event schema, occurrence lifecycle, ambient-clock, catch-up, worker, or execution authority is added.

** Verification
:PROPERTIES:
:CUSTOM_ID: verification
:END:
Strict RED→GREEN CLI integration tests prove interior and final pages, complete exact provenance, deterministic cursors, pre-storage ID and page-size validation, missing and absent evidence, invalid starts, fail-closed exact corruption, and isolation from unrelated corruption. The complete repository quality gate must remain green.

** Revisit when
:PROPERTIES:
:CUSTOM_ID: revisit-when
:END:
Reconsider before persisting occurrence identities or cursors, defining catch-up or due policy, generating schedule or task identities, materializing, claiming, cancelling, retrying, dispatching, adding workers, reading ambient time, or executing work.
