* Architecture Decision Records
:PROPERTIES:
:CUSTOM_ID: architecture-decision-records
:END:
Project Vela uses lightweight Architecture Decision Records (ADRs) for decisions that materially shape the kernel, security model, persistence formats, extension boundaries, or development process.

** Status values
:PROPERTIES:
:CUSTOM_ID: status-values
:END:
- =proposed=
- =accepted=
- =superseded=
- =rejected=

** Naming
:PROPERTIES:
:CUSTOM_ID: naming
:END:
Use a four-digit sequence and concise slug:

#+begin_src text
0001-use-small-in-house-kernel.org
0002-use-append-only-event-log.org
#+end_src

Copy [[file:template.org][=template.org=]], fill every section, and link the related issue and pull request. If a later ADR changes the decision, preserve the original and mark it superseded.
