* ADR-0092: Read-only bounded finite recurrence inventory CLI paging
:PROPERTIES:
:CUSTOM_ID: adr-0092-read-only-bounded-finite-recurrence-inventory-cli-paging
:END:
- *Status:* accepted
- *Date:* 2026-08-07
- *Decision and execution issue:* [[https://github.com/Knosence9/project-vela/issues/985][#985]]
- *Related:* ADR-0041, ADR-0090, ADR-0091

** Context
:PROPERTIES:
:CUSTOM_ID: context
:END:
ADR-0091 exposes allocation- and replay-bounded exact-ID keyset paging through =RecurrenceStore::list_page=. Operators otherwise need custom kernel code to use it and could duplicate page-size validation, cursor interpretation, diagnostics, serialization, or storage authority policy.

The smallest responsible adapter should preserve the kernel's canonical selected-window validation and existing complete recurrence representation without introducing a second cursor or filtering contract.

** Decision
:PROPERTIES:
:CUSTOM_ID: decision
:END:
Add =vela-dev recurrence page DATABASE PAGE_SIZE [AFTER]=. =PAGE_SIZE= must form a positive, at-most-1024 =RecurrencePageSize=. Optional =AFTER= must form one exact non-blank =RecurrenceId=; it is an exclusive caller-owned keyset cursor and need not identify an existing definition. Both inputs are validated before storage access.

The command opens only the selected existing database through =RecurrenceStore::open_read_only= and delegates selection to =RecurrenceStore::list_page=. Success emits compact ={"recurrences":[...],"next_after":...}= JSON. Recurrences reuse the complete inventory object, retain exact-ID ordering, and preserve JSON-escaped caller-authored strings and lifecycle evidence. =next_after= contains the last emitted exact ID only when the kernel validated a lookahead; terminal, empty, and beyond-end pages emit =null=.

Invalid sizes and cursors emit =invalid_recurrence_page_size= and =invalid_recurrence_id= before storage access. Missing or incompatible storage, selected-window corruption, projection failures, and serialization failures emit =recurrence_page_inspection_failed=, return non-zero, and emit no partial stdout. Missing storage is never created.

The command reads no clock, mutates nothing, persists no cursor, and grants no status-filtered discovery, lifecycle, worker, lease, dispatch, retry, permission, or execution authority.

** Alternatives considered
:PROPERTIES:
:CUSTOM_ID: alternatives-considered
:END:
*** Add paging flags to =recurrence inspect=
:PROPERTIES:
:CUSTOM_ID: add-paging-flags-to-recurrence-inspect
:END:
Rejected because a distinct output shape with continuation evidence deserves an explicit command and keeps the existing complete-inventory contract behavior-compatible.

*** Accept an empty cursor as the first page
:PROPERTIES:
:CUSTOM_ID: accept-an-empty-cursor-as-the-first-page
:END:
Rejected because =RecurrenceId= has one canonical non-blank validation contract. Cursor absence already represents the first page without inventing a sentinel identity.

*** Add lifecycle status filtering
:PROPERTIES:
:CUSTOM_ID: add-lifecycle-status-filtering
:END:
Rejected because the existing storage shape cannot bound the number of nonmatching definitions scanned to fill one result page. ADR-0091 deliberately leaves bounded status paging as a separate index or sparse-cursor decision.

** Consequences
:PROPERTIES:
:CUSTOM_ID: consequences
:END:
- Operators can traverse recurrence definitions without complete-inventory replay or allocation.
- CLI cursor and lookahead behavior remain identical to the kernel contract.
- Selected lookahead corruption fails closed while corruption outside the selected window remains isolated.
- Existing complete and status-filtered inventory commands remain unchanged.
- No schema, event, mutation, clock, or execution authority is added.

** Verification
:PROPERTIES:
:CUSTOM_ID: verification
:END:
Strict RED→GREEN CLI tests prove exact-ID ordering, continuation without overlap, terminal and empty results, exact string escaping, size and cursor validation before storage access, missing-storage non-creation, selected-lookahead failure, and corruption isolation outside the bounded window. The complete repository quality gate must remain green.

** Revisit when
:PROPERTIES:
:CUSTOM_ID: revisit-when
:END:
Reconsider before adding status-filtered pages, snapshot tokens across calls, destructive deletion, resume or undo semantics, clocks, workers, leases, dispatch, permissions, retries, or execution.
